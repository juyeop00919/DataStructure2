# 과제 14: 힙 정렬, 퀵 정렬 및 병합 정렬의 성능 비교 분석

## 1. 실험 개요 및 환경
본 실험에서는 무작위 정수 배열에 대하여 대표적인 $O(n \log n)$ 정렬 알고리즘인 **힙 정렬(Heap Sort)**, **병합 정렬(Merge Sort)**, **퀵 정렬(Quick Sort - First, Random, Median-of-Three)**을 수행하고, 데이터 크기($n = 1,000 \sim 20,000$)에 따른 **숫자 비교 횟수, 실행시간, 최대 추가 메모리 사용량**을 비교·분석하였다.

- **데이터 크기 ($n$)**: 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 20,000
- **데이터 조건**: `0 ~ 99,999` 범위의 무작위 정수 (중복 허용, 모든 알고리즘에 동일한 원본 배열 복사본 사용)
- **측정 방식**: 실행시간의 미세 오차를 줄이기 위해 각 데이터 크기별로 **1,000회 반복 실행한 평균값**을 산출하였으며, 운영체제 및 아키텍처는 64비트(포인터 8 Bytes, `int` 4 Bytes) 환경을 기준으로 측정하였다.
