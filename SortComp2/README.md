# 과제 - 11: 삽입 정렬과 쉘 정렬의 성능 비교 및 분석

## 1. 실험 결과 요약

무작위 정수 데이터를 생성하여 크기(n)가 증가함에 따라 삽입 정렬과 두 가지 쉘 정렬 방식의 데이터 비교 횟수를 측정한 결과입니다.

| 데이터 크기 (n) | 삽입 정렬 (Insertion Sort) | 쉘 정렬 (Original Gap) | 쉘 정렬 (Knuth Gap) |

| **1,000** | 255,621 | 15,153 | 13,780 |

| **4,000** | 4,027,334 | 85,870 | 76,531 |
| **8,000** | 15,986,774 | 199,921 | 178,198 |
| **16,000** | 64,061,137 | 483,411 | 411,943 |
| **20,000** | 99,675,472 | 581,461 | 527,282 |

## 2. 데이터 크기 증가에 따른 성능 변화 분석

* **삽입 정렬의 $O(n^2)$ 증가 추이:** 
  데이터 크기가 1,000개에서 2,000개로 2배 증가할 때 비교 횟수는 약 25만 회에서 100만 회로 약 4배 증가했습니다. 8,000개에서 16,000개로 증가할 때도 1,598만 회에서 6,406만 회로 약 4배가 뛰었습니다. 이는 삽입 정렬의 시간 복잡도가 $O(n^2)$임을 실험적으로 명확히 증명합니다.
* **쉘 정렬의 효율적인 증가 추이:** 
  반면 쉘 정렬(Knuth 기준)은 데이터가 1,000개에서 2,000개로 2배 증가할 때 비교 횟수가 약 2.3배(13k → 32k) 증가하는 데 그쳤습니다. 데이터가 20,000개일 때 삽입 정렬은 거의 1억 번의 비교를 수행하지만, 쉘 정렬은 50~58만 번 수준으로 억제되어 데이터 크기가 커질수록 성능 격차가 기하급수적으로 벌어집니다.

---

## 3. 삽입 정렬과 쉘 정렬의 성능 차이 발생 원인

삽입 정렬은 항상 **인접한 원소끼리만 비교하고 교환**합니다. 만약 배열의 가장 뒤쪽에 아주 작은 숫자가 위치해 있다면, 이 숫자를 제자리(앞쪽)로 보내기 위해 배열의 전체 길이만큼 비교와 이동을 반복해야 합니다. 이로 인해 최악의 경우와 평균적인 무작위 배열에서 비효율이 발생합니다.

반면 쉘 정렬은 일정한 **간격을 두고 떨어진 원소들끼리 그룹을 지어 삽입 정렬을 수행**합니다. 이 과정을 통해 데이터가 배열의 양쪽 끝에서 반대편으로 단번에 크게 이동할 수 있습니다. 
삽입 정렬은 '거의 정렬된 배열'에 대해서는 비교 횟수가 매우 적은 **O(n)** 의 성능을 낸다는 특징이 있는데, 쉘 정렬은 큰 간격으로 먼저 대략적인 부분 정렬을 마친 뒤 간격을 점차 좁혀가기 때문에, 마지막 간격이 1이 되어 수행하는 일반 삽입 정렬 단계에서는 이미 데이터가 '거의 정렬된 상태'가 되어 있어 비교 횟수가 극단적으로 줄어들게 됩니다.

## 4. 간격 수열에 따른 성능 차이 (Original vs Knuth)

실험 결과 모든 데이터 크기 구간에서 **Knuth 간격 수열이 기본 간격 수열보다 비교 횟수가 약 10% 이상 적게 발생**하며 우수한 성능을 보였습니다. 
특히 데이터가 20,000개일 때 기본 간격은 약 58만 번을 비교했지만, Knuth 간격은 약 52만 번으로 6만 번 이상의 불필요한 연산을 절약했습니다.

### 간격 수열이 쉘 정렬의 성능에 영향을 미치는 이유
쉘의 기본 간격 수열(N/2, N/4, ..., 1)은 짝수/홀수 인덱스 간의 교류가 마지막 `gap=1`이 되기 전까지 전혀 발생하지 않는다는 치명적인 약점이 있습니다. 예를 들어 간격이 8, 4, 2로 줄어드는 동안 짝수 인덱스는 짝수 인덱스끼리만 섞이고 홀수는 홀수끼리만 섞입니다. 이 경우 마지막 `gap=1` 단계에서 많은 비교와 이동이 한꺼번에 몰려서 발생하게 됩니다. (서로 공약수를 공유하기 때문입니다.)

반면 **Knuth 수열(1, 4, 13, 40, 121...)은 항들 사이에 1을 제외한 공약수가 없는 서로소(Coprime)에 가까운 형태**를 띱니다. 이러한 수열을 사용하면 간격이 줄어드는 매 단계마다 원소들이 더욱 다양한 위치의 원소들과 섞이게 되므로, 배열 전체가 훨씬 균일하게 부분 정렬됩니다. 그 결과 마지막 단계인 `gap=1` 정렬에서 원소들이 제자리를 찾아가기 위해 이동해야 하는 거리가 최소화되어 전체적인 비교 횟수가 크게 감소하는 것입니다.
